# Brain

A few plain markdown pages about your own work. The card is built from these, so it stays true as you build more.

You don't need all of it on day one. Fill in `stack.md` and `proof.md` first, the rest when you have time.

| Page | What goes in it |
|---|---|
| [me.md](me.md) | Who you are, your role, where you're heading |
| [stack.md](stack.md) | Tools you actually use, and what for |
| [proof.md](proof.md) | Things you built or shipped, with real numbers |
| [voice.md](voice.md) | How you write, so drafts sound like you |
| [log.md](log.md) | One line per week: what you built, what changed |

Rules:
- Only write what's true. If you're not sure about a number, leave a `TODO:` instead of guessing.
- Keep anything private out if your repo is public: salary, clients who haven't agreed to be named, your employer's internal numbers.
- Link pages with `[[page-name]]` if you want. It's just markdown.

To update the card from these pages, see [PROMPT.md](../PROMPT.md) (by hand) or the README section on the weekly update (automatic).
